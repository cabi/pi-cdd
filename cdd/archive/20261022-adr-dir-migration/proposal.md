# adr-dir-migration

## Why

The store's decision record is split across two homes: root `decisions/` (product-era ADRs 0001–0007) and `cdd/decisions/` (loop-era 0008–0011). The drift guard's A-checks scan only `cdd/decisions/`, so seven of eleven ADRs — including the gherkin-law verdicts every spec inherits — have never been enforced: a staged `git mv` of the seven fires the guard's first-ever product-era finding (`[A0]` on 0005's annotated status). Rule 10 already says decisions live under `cdd/`; the law's rule 2a still documents the split it must retire.

## What Changes

- `git mv` ADRs 0001–0007 into `cdd/decisions/` (the root directory disappears) so history follows and the guard's A-checks govern all eleven ADRs — commit M with a `Mechanical-Change:` trailer (L2 travel exemption; no spec or acceptance file rides in it).
- ADR-0005 frontmatter normalized to guard-enum `status: superseded`, the annotation preserved verbatim as a body line — lifecycle bookkeeping (director-blessed), not decision content.
- The loop law's rule 2a decisions-split sentence becomes the single-home sentence (lib/loop-law.mjs, the sole source); the cdd/rules.md mirror regenerated byte-identically (SSL3).
- Every live reference to the old split simplifies to the one home: README.md Layout loses the stale `decisions/` line; skills/cdd-adr-review/brief-adr.md's root-vs-cdd note, the SKILL.md example paths, and the lib/gherkin.mjs comment name `cdd/decisions/`.
- New `adr` capability owns `cdd/decisions/000[1-7]-*.md`; gherkin's "Declarative style" Code: drops the root 0007 entry (one capability per file, O-check clean).
- Reconfirmed-by paragraphs in ADR-0006, 0007, 0009, 0010, 0011 (A2 remedy, feature commit F).
- Acceptance: SSL2b repinned to the single-home sentence and a new tests/acceptance/decisions-home.test.js pinning the migrated layout and the guard's green full scan — both RED first.

## Solutions Considered

- adr: the existing guard A-checks (cdd/scripts/spec-drift.mjs A0/A1/A2) — adopted; the move makes them apply to 0001–0007 unchanged, no new enforcement code. Considered teaching the guard to scan both directories: rejected — it keeps the split, doubles scan topology, and contradicts rule 10's one home. Considered symlinks from the root: rejected — git history and guard enumeration both break.
- gherkin: the existing single-source law (ADR-0009, lib/loop-law.mjs lawRule2a with the SSL3 byte-identity mirror pin) — adopted; the sentence is already single-sourced, this change edits it in place.

## Non-Goals

- No renaming or renumbering of ADRs, and no copy-editing of product-era decision content beyond 0005's status normalization.
- No Layout replacement line for cdd/decisions in README.md — the Layout section lists no cdd/ children (director decision).
- No edits to archived reviews or cdd/archive/ records — history stays as written.
